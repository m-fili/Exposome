Set the gate passphrase

Local utility. Nothing is sent anywhere — hashing happens in this browser tab.

Reminder: the gate is a speed bump, not access control. Everything on the site is readable in the public repository regardless of the passphrase. Do not rely on it to protect anything that would be harmful to disclose.

  1. Type the passphrase above.
  2. Copy the generated line.
  3. In assets/gate.js, replace the var PASS_HASH = ''; line with it.
  4. Commit and push. Share the passphrase with collaborators out of band.

To turn the gate off again, set PASS_HASH back to an empty string.
